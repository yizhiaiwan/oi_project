# 逆元

## 逆元的概念

- 若 $a\times b\equiv 1\pmod p$，则称 $b$ 是 $a$ 模 $p$ 意义下的逆元，记作 $a^{-1}$
- 逆元把除法变成乘法: $(a\div b)\bmod p = a\times b^{-1}\bmod p$
- 逆元存在的条件: $\gcd(a,p)=1$ (费马小定理还额外要求 $p$ 为质数)

---

## 快速幂

逆元和组合数的计算中经常用到快速幂，所以先总结快速幂

```c++
// 快速幂
int q_pow(int a,int b,int p) {
    int res = 1;
    while (b) {
        if (b&1) res = res * a % p;
        a = a * a % p;
        b >>= 1;
    }
    return res;
}
```

## exgcd 求逆元

```c++
// 扩展欧几里得算法: 求 ax+by = gcd(a,b) 的解
int exgcd(int a,int b,int &x,int &y) {
    if (b == 0) {
        x = 1, y = 0;
        return a;
    }
    int d = exgcd(b, a%b, y, x);
    y -= a/b * x;
    return d;
}

// exgcd 求逆元
int inv_i(int a, int m) {
    int x, y;
    int d = exgcd(a, m, x, y);
    // d==1 时逆元存在，x即为逆元
    return (x % m + m) % m; // 调整为正数
}
```

## 费马小定理求逆元

- 费马小定理: 若 $p$ 为质数且 $\gcd(a,p)=1$，则 $a^{p-1}\equiv 1\pmod p$
- 所以 $a$ 的逆元就是 $a^{p-2}$，用快速幂来求

```c++
// 费马小定理
int inv(int a,int m) {
    return q_pow(a,m-2,m);// 快速幂
}
```

## 线性递推求 1~n 的逆元

- 只要求出 $inv[1]=1$，就能用公式 $inv[i]=(p-p/i)\times inv[p\%i]\bmod p$ 递推出所有逆元
- 要求 $p$ 为质数且 $n<p$

```c++
// 线性递推求1~n的逆元
int inv[N];
inv[1] = 1;
for (int i = 2;i<=n;i++) {
    inv[i] = (p-p/i)*inv[p%i]%p;
}
```

## 预处理阶乘与阶乘的逆元(求组合数)

```c++
// 预处理阶乘与阶乘的逆元 (p 为质数且 n < p)
int fac[N], inv[N];
void init(int n,int p) {
    fac[0] = 1;
    for (int i = 1;i<=n;i++) fac[i] = fac[i-1]*i%p;
    inv[0] = 1, inv[1] = 1;
    for (int i = 2;i<=n;i++) inv[i] = (p-p/i)*inv[p%i]%p; // 线性递推求逆元
    for (int i = 2;i<=n;i++) inv[i] = inv[i-1]*inv[i]%p;  // 乘成阶乘的逆元
}

// 求组合数 C(n,m) mod p
int C(int n,int m,int p) {
    if (m > n) return 0;
    return fac[n] * inv[m] % p * inv[n-m] % p;
}
```

## Lucas 定理

- Lucas 定理: 当 $p$ 为质数且 $n,m$ 很大时，$C(n,m)\equiv C(n\bmod p,m\bmod p)\times C(n/p,m/p)\pmod p$

```c++
// Lucas 定理主函数
int lucas(int n,int m,int p) {
    if (m == 0) return 1;
    return C(n % p, m % p, p) * lucas(n / p, m / p, p) % p;
}
```
