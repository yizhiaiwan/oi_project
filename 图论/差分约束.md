# 差分约束

## 差分约束的概念

1. 差分约束不是一个单一的算法，而是一类可以用图来建模的不等式约束问题。
2. 典型形式是 $x_i-x_j\le c$，可以把它转换成有向图中从 $j$ 到 $i$ 的一条权为 $c$ 的边。

### 为什么差分约束常用[ spfa ](spfa.md)来实现
* SPFA 是一种求最短路径的图论算法。
* 差分约束可以转化为最短路径松弛问题，SPFA 用松弛操作把所有不等式约束收敛到一个可行的最小值解。
* 这种建模下，若图中存在负权环，则说明约束组无解；若不存在负权环，则 SPFA 可以给出一个可行解。
* SPFA 是常用实现之一，Bellman-Ford 也可以，因为它们本质上都是在做松弛和负权环检测。

## 差分约束的实现

* 差分约束的核心是建图：把一个不等式转化为一条有向边。
* 对约束 $x_i-x_j\le c$，构造边 $j\to i$，权重为 $c$。
* 对约束 $x_i-x_j\ge c$，等价变形为 $x_j-x_i\le -c$，构造边 $i\to j$，权重为 $-c$。
* 如果题目要求求最大值，可以通过取反或改写约束的方式，仍然将问题转成最短路/负环检测。
* 常用技巧是加一个超级源点 0，向所有节点连一条权为 0 的边，使得图连通，SPFA 可以从 0 出发处理所有节点。

注意要点：
  1. 标准差分约束无解的判断是“是否存在负权环”，而不是正环。
  2. 建边时要看清楚方向和权值符号。通常 $x_i-x_j\le c$ 对应 $j\to i$，权为 $c$。

### 示例代码(当然也是模板题代码):
[原题链接](https://www.luogu.com.cn/problem/P5960)
```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 5e3+10;
int n,m;
int dis[N],cnt[N];
bool vis[N];
struct edge
{
    int v,w;
};
vector<vector<edge>> g(N);
bool spfa(int s)
{
    memset(dis,0x3f,sizeof dis);
    memset(vis,0,sizeof vis);
    memset(cnt,0,sizeof cnt);
    queue<int> que;
    que.push(s);
    vis[s] = true;
    dis[s] = 0;
    while(!que.empty())
    {
        int u = que.front();
        que.pop();
        vis[u] = false;
        for (auto [v,w]:g[u])
        {
            int new_dis = dis[u]+w;
            if(dis[v] > new_dis)
            {
                dis[v] = new_dis;
                cnt[v] = cnt[u]+1;
                if(cnt[v] > n) return false;
                if(!vis[v])
                {
                    que.push(v);
                    vis[v] = true;
                }
            }
        }
    }
    return true;
}
int main()
{
    scanf("%d%d",&n,&m);
    for (int i = 1; i <= m; i++)
    {
        int u,v,w;
        scanf("%d%d%d",&u,&v,&w);
        // 题目给出的约束通常是 x_u - x_v <= w
        // 对应差分约束边 v -> u, 权重为 w
        g[v].push_back({u,w});
    }
    for (int i = 1; i <= n; i++)
    {
        // 为了保证图连通，添加超级源点 0
        // 0 -> i, 权为 0
        g[0].push_back({i,0});
    }
    if(!spfa(0)) printf("NO");
    else{
        for (int i = 1; i <= n; i++)
        {
            printf("%d ",dis[i]);
        }
    }
}
```

## 优秀真题

1. [P5960 【模板】差分约束](https://www.luogu.com.cn/problem/P5960)
    > 模板题，必刷
2. [P1993 小 K 的农场](https://www.luogu.com.cn/problem/P1993)
    > 三种约束条件，所以我们要把三种约束转换成一种约束，这也是一道很好的差分约束基础题，可以检验你差分约束有没有学懂
3. [P6145 [USACO20FEB] Timeline G](https://www.luogu.com.cn/problem/P6145)
    > 超级源点的应用，超级源点就是设置一个虚点来链接所有其他点，使得 spfa 算法可以跑所有情况
4. [P4878 [USACO05DEC] Layout G](https://www.luogu.com.cn/problem/P4878)
    > 数据的严格排序(或者说是约束)，考察对题目和约束的理解
5. [P3084 [USACO13OPEN] Photo G](https://www.luogu.com.cn/problem/P3084)
    > 巧妙的把区间问题转换成一个不等式问题：$1\in\{l,r\}\Rightarrow r-l\le1$
6. [P2474 [SCOI2008] 天平](https://www.luogu.com.cn/problem/P2474)
    > 字符串处理+floyd+差分约束统计合法数量，是一道难题，值得挑战
