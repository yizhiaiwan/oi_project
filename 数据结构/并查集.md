# 并查集


## 并查集的概念

- 并查集算是一种**数据结构**,可是它更像一种对集合的处理
- **首先** 并查集顾名思义就是集合的**合并与查询**
- **其次** 并查集可以表示**两个**集合之间的**关系**
- 所以并查集通常用来处理**连通块问题**

## 并查集的实现

* 在C++中，我们通常使用一个数组来表示并查集，而数组中的**值**则表示他的***父亲***
* 如果两个值是一样的，则代表这两个点属于**一个集合**内

### 初始化

* 由于初始数组都为 $0$，所以我们要把每个点都绑到**自己的点**上，也就是把 $n_i$ 设为 $i$

    代码实现：
    ```c++
    for (int i = 1; i <= n; i++) {
        f[i] = i;
    }
    ```

    ---

### 查询

* 就是查看这个点目前**所在的集合**，利用递归的特性找**父亲**，直到它指向自己，就结束

    图例解释:

    ![查询图例](/picture_date/并查集查询图例.png)

    代码实现:

    ```c++
    int find(int x) {
        if (f[x] != x) {
            return find(f[x]); // 查询自己的父亲
        }
        return f[x];
    }
    ```

### 路径压缩

* 路径压缩属于是查询的**进阶**，把查询的**时间复杂度**进一步从 $O(n)$ 降低为 $O(\alpha(n))$
* 具体实现就是在返回时直接把**自己**的**父亲**变成**递归传回来**的**父亲**，也就是整个**并查集**的**祖宗**
* 这样做的好处就是**降低**了**时间复杂度**，坏处就是会破坏**集合**的**结构**

    图例解释:

    > 这是把上图路径压缩后的结果

    ![路径压缩图例](/picture_date/路径压缩图例.png)

    代码实现:
    ```c++
    int find(int x) {
        if (f[x] != x) {
            f[x] = find(f[x]); // 在递归时把自己变成传回来的值(唯一修改)
        }
        return f[x];
    }
    ```

    ---

### 合并

* 合并是最关键的操作，就是合并两个集合，使得**两个集合**合并成**一个集合**，用代码具体实现就是把一个集合的**父亲节点**指向另一个集合的**父亲节点**

    > **注意: 合并永远是*父节点*合并**

    图例解释:

    ![合并图例](/picture_date/合并图例.png)

    代码实现:

    ```c++
    void merge(int x, int y) {
        int root_x = find(x), root_y = find(y); // 找两个集合的父节点
        if (root_x != root_y) {
            f[root_x] = root_y; // 合并两个集合
        }
    }
    ```

### 按秩合并

* 按秩合并就是尽量让**节点数少的**集合连接**节点数多的**集合或者是树**高**
* 与路径压缩一起使用可以达到 $O(\alpha(n))$

    > **注意: 按秩合并需要额外维护一个 sz 数组(集合大小)，初始化时把 sz[i] 设为 1**

    图例解释: (与上图一样)

    ![按秩合并](/picture_date/合并图例.png)

    代码实现:

    ```c++
    void merge(int x, int y) {
        int root_x = find(x), root_y = find(y); // 找两个集合的父节点
        if (root_x != root_y ){
            if (sz[root_x] > sz[root_y]) swap(root_x,root_y); // 确保root_y是大的
            f[root_x] = root_y; // 合并两个集合
            sz[root_y] += sz[root_x]; // 更新集合大小
        }
    }
    ```
