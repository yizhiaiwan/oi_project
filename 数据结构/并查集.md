# 并查集（Disjoint Set Union，DSU）

## 概要
并查集是一种高效维护集合合并与查询的数据结构，常用于连通性、离线查询、分组关系检测等问题。

## 主要操作与实现

1. 初始化
```cpp
for(int i=1;i<=n;i++) f[i]=i, sz[i]=1;
```

2. 查找（带路径压缩）
```cpp
int find(int x){
    if(f[x]==x) return x;
    return f[x] = find(f[x]); // 路径压缩
}
```

3. 合并（按大小/按秩）
```cpp
void unite(int x,int y){
    x = find(x); y = find(y);
    if(x==y) return;
    if(sz[x] > sz[y]) swap(x,y); // 保证 x 是小集合
    f[x] = y;
    sz[y] += sz[x];
}
```

## 优化与拓展
- 路径压缩 + 按秩/按大小合并，摊还复杂度约为 O(α(n))。  
- 带权并查集：在 find/merge 中维护与父节点的相对权值（用于食物链、差值关系等题目）。  
- 扩展域并查集：通过多倍开数组表示多种关系（例如把一个元素拆成多个状态来表示不同关系）。
