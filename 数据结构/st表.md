# st 表

## 概要
st 表（Sparse Table）是一种针对静态数组的区间最值/最小值查询的数据结构，查询 O(1)、预处理 O(n log n)。适用于数组不发生修改的场景。

## 何时使用
- 数组不修改、需要大量区间最值/最小值查询
- 与线段树/单调队列对比：线段树支持修改但查询 O(log n)，单调队列用于滑动窗口，st 表查询最快但无法修改

## 实现要点
1. 预处理：计算 lg[]（快速取对数）和 st[k][i]（长度为 2^k，起点 i）的值。

```cpp
// 预处理示例（取最大值）：
int lg[N];
void build_lg(int n){
    lg[1]=0; for(int i=2;i<=n;i++) lg[i]=lg[i/2]+1;
}

void build_st(int n){
    for(int i=1;i<=n;i++) st[0][i]=a[i];
    for(int k=1;(1<<k)<=n;k++){
        for(int i=1;i+(1<<k)-1<=n;i++){
            st[k][i]=max(st[k-1][i], st[k-1][i+(1<<(k-1))]);
        }
    }
}
```

2. 查询：用长度的二进制表示合并两个重叠区间。

```cpp
int query(int l,int r){
    int k = lg[r-l+1];
    return max(st[k][l], st[k][r-(1<<k)+1]);
}
```

## 复杂度
- 预处理：O(n log n)
- 单次查询：O(1)
- 空间：O(n log n)

## 拓展
- 可把模板中的 max 替换为 gcd/min/其他满足结合律的函数来处理不同问题。
- 二维 st 表用于矩阵或二维静态查询（预处理与查询思想相同，注意索引和空间成本）。
