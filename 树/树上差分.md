# 树上差分

## 概要
树上差分把路径更新/查询问题转化为点差分或边差分，再通过一次树形前缀和（dfs）聚合答案，适用于需要对路径做批量加/减操作的题目。

## 基本思想
- 点差分（path add）：对路径 x—y 增加值 val 时，���做 d[x]+=val, d[y]+=val, d[lca]-=val, d[parent(lca)]-=val，最后在一次 dfs 回溯聚合。  
- 边差分（edge add）：若题目要求对边加权，同样通过把贡献记在子节点或父节点上把边更新转为点更新，再聚合。

## 点差分示例：
```cpp
int l = lca(x,y);
d[x] += v;
d[y] += v;
d[l] -= v;
d[f[l][0]] -= v;

// 最后一次 dfs 聚合
void dfs2(int u,int p){
    for(int v:g[u]) if(v!=p){
        dfs2(v,u);
        d[u] += d[v];
    }
    // 此处 d[u] 为合并后的值（或用于计算答案）
}
```

## 边差分示例（将边的权值下放到子节点）：
```cpp
// 若更新的是边，通常把更新记在子节点上，例如把路径两端记 +v，LCA 减 2v
d[x] += v; d[y] += v; d[l] -= 2*v;
```

## 复杂度
- 每个更新/查询为 O(log n) 用于求 LCA（若使用倍增），批量更新后聚合为一次 O(n) dfs。总体常为 O((n+q) log n)。

## 注意与陷阱
- 处理 parent(lca) 时需判空（根的 parent 可能为 0），避免越界。  
- 更新值的符号和减法位置要严格按模型执行（点差分与边差分的公式不同）。  
- 若更新包含权值或拓展域（例如带权并查或多个属性），在差分模型上扩展维度或用多数组表示。
