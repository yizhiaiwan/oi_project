# 树上差分

## 树上差分的概念

- 树上差分，顾名思义，就是把树看成差分数组来做差分
- 所以树上差分是一种可以快速修改一部分树的值的方法

## 树上差分的实现

- 树上差分分为点差分与边差分

---

### 点差分

1. 对树进行差分处理

    > 注意:对树的点差分是要把一个树拆成两个部分来算的，一个是左边到LCA，一个是右边到LCA的父亲

    图例演示:

    ![树上差分](/picture_date/树上差分图例.png)

    代码演示:

    ```c++
    int lca = LCA(x,y);
    d[x]++,d[y]++,d[lca]--,d[f[lca][0]]--;
    ```

2. 对树进行前缀和处理

    代码演示:

    ```c++
    void dfs2(int x,int pre) {
        for (auto& i:g[x]) {
            if (i!=pre) {
                dfs2(i,x);
                d[x]+=d[i];
            }
        }
        ans = max(d[x],ans);
    }
    ```

### 边差分

- 边差分其实就是把边的值做一个边权下放使得边差分变成点差分
- 所以就会变成计算两边的值不算LCA

图例:

![树上边差分](/picture_date/树上差分(边差分).png)

代码示例:
```c++
int lca = LCA(i,j);
d[i]++,d[j]++,d[lca]-=2;
```
后边的前缀和不变
